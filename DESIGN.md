# Design direction — Personal Field Guide

Portfolio Mobile uses a calm, monochrome field-guide language: paper surfaces,
black type, quiet rules, and a single accent for the selected project. The
project content leads the experience; controls remain native-feeling and
compact.

- Platform: Flutter app with a public web preview and native targets.
- Palette: white paper, charcoal ink, soft gray dividers, one accent state.
- Structure: project index, project detail, skills, and contact surfaces.
- Interaction: tap targets remain comfortable; previously visited content is
  intended to work offline when the native cache is available.
- Release boundary: web preview is public; native store distribution is not yet
  claimed.
